## 先说结论：它到底想解决什么问题

雨云对象存储走的是 **S3 协议兼容** 路线，也就是说你用 boto3、aws-sdk、rclone、PicGo、Chevereto、Alist、Cloudreve、NextCloud 这些原本对接 AWS S3 的工具，基本不用改代码，换一下 endpoint 和密钥就能直接跑。这一点对"从大厂迁过来"的场景非常友好，迁移成本几乎为零。

它的核心卖点可以归纳成几条：

- **计费只有两项**：存储空间 + 下载流量。没有请求次数费、没有 HTTPS 附加费、没有操作类型分级，账单一眼能看懂。
- **自带 WAF 防火墙**：防盗链（Referer 校验）、单 IP / 全局速率限制、JS 验证防 CC、IP 黑白名单。这些功能在传统小厂对象存储里很少见，做图床尤其怕被刷流量，这块很对路。
- **弹性计费可一键关**：套餐用完默认停访问，想继续用就开弹性，怕爆账单就关掉，5–10 分钟自动停上传或下载，不会一觉醒来欠费几百块。
- **自定义域名 + SSL 证书中心联动**：能绑自己域名，证书自动续。
- **同区域服务器内网互访免流量**：如果你雨云的服务器和对象存储在同区域，走内网地址上下传都不算流量，做站源分离很划算。

有 B 站 up 主实测下载能跑到 80MB/s 以上（具体看你线路和地区），防流量盗刷的 CC 防火墙也是实测可用的，不是宣传话术。
